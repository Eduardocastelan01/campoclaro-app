# CampoClaro — Calculadora Financiera Agrícola

**Demo en vivo:** [campoclaro-je.netlify.app](https://campoclaro-je.netlify.app)  
**Autor:** José Eduardo López Castelán

Aplicación web progresiva (PWA) para productores agrícolas mexicanos.
Calcula rentabilidad, compara precios de venta y guarda historial de zafras.
Funciona sin internet una vez instalada.

## Funcionalidades
- 10 cultivos: caña, maíz, limón, café, plátano, mango, chile, frijol, naranja, sorgo
- Modo rápido (costo total) o detallado (10 categorías de gastos)
- Comparativo de hasta 3 escenarios de precio (ingenio, coyote, otro)
- Semáforo de viabilidad financiera
- Estimado de capacidad crediticia (criterio FIRA 40%)
- Historial persistente sin cuenta ni servidor

## Uso
Abre `index.html` en cualquier navegador. Sin instalación, sin dependencias.
